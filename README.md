# Fifteen Rooftop — concept website

Premium, responsive Next.js concept site prepared as a sales demonstration for Fifteen Rooftop, Nairobi.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy

Push this project to a new GitHub repository, import that repository into Vercel, and deploy with the detected Next.js defaults.

## Important demo notes

- This is an independent, unofficial concept prepared for a proposal. It is not approved by or affiliated with Fifteen Rooftop.
- Contact details and location are based on publicly supplied listing information; verify them with management before launch.
- Menu photography is illustrative. The live menu, prices, opening hours, events, booking workflow and social links need confirmation from the restaurant.
- Reservation enquiry currently opens WhatsApp at the listed number. No booking is confirmed automatically.
- Photography uses remote Unsplash image URLs and should be replaced with licensed/owner-approved venue photography before production.
